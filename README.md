# 超市商品销售管理系统

## 1. 项目简介

本系统是一个基于 `Flask + PostgreSQL` 开发的超市商品销售管理系统，主要面向三类用户：

- 系统管理员
- 超市主管
- 销售人员

系统围绕“商品管理、销售管理、订单管理、利润统计、角色权限控制”等内容展开，适合用于数据库系统课程项目展示与演示。

---

## 2. 系统主要功能

### 2.1 系统管理员
系统管理员主要负责用户管理，包括：

- 查看系统用户
- 按关键字查询用户
- 新增用户
- 修改用户信息
- 删除用户

### 2.2 超市主管
超市主管主要负责商品和库存管理，包括：

- 查看商品信息
- 商品搜索
- 商品快速上架
- 商品补货
- 商品价格维护
- 商品下架
- 查看库存预警
- 查看库存总价值
- 查看库存总可赚利润
- 查看销售统计看板
- 按时间范围查看营业额、成本、利润、订单数

### 2.3 销售人员
销售人员主要负责销售业务，包括：

- 查询商品
- 将多个商品加入同一订单
- 一次性结算为一笔订单
- 查看自己的销售记录
- 按时间范围筛选销售记录
- 查看自己的营业额、订单数、利润
- 查看个人业绩和销售排行榜

---

## 3. 项目目录说明

项目主要文件如下：

- `app.py`：Flask 主程序，负责路由和页面跳转
- `auth.py`：用户登录认证、密码加密
- `db_conn.py`：数据库连接配置
- `init_db.py`：数据库初始化脚本
- `product_manage.py`：商品、库存、利润相关逻辑
- `sale_manage.py`：销售、订单、统计相关逻辑
- `user_manage.py`：用户管理逻辑
- `templates/`：前端页面模板
- `static/`：静态资源文件（图片、样式等）
- `start（双击进入系统）.bat`：Windows 下快速启动脚本

## 4. 运行环境要求

在运行本项目之前，需要准备以下环境：

本项目当前数据库连接配置位于 `db_conn.py` 中，默认参数如下：

- 主机：`localhost`
- 端口：`15432`
- 数据库名：`supermarket`
- 用户名：`appuser`
- 密码：`123456St$`

也就是说，运行项目前，你需要确保本地存在一个可以访问的 PostgreSQL 服务，并且该服务满足上述连接信息。

---

## 6. Docker 使用说明

如果你的 PostgreSQL 是通过 Docker 容器运行，请先完成以下操作：

### 6.1 启动 Docker Desktop
先手动打开 `Docker Desktop`，并确保 Docker 已经正常运行。

### 6.2 启动 PostgreSQL 容器
你需要确保 PostgreSQL 容器已经启动，并且映射到了本机端口：

- `15432 -> 5432`

也就是说，程序访问的是本地的 `15432` 端口，而不是 PostgreSQL 默认的 `5432`。

### 6.3 检查数据库是否可连接
在运行项目之前，请确认：

- 数据库容器已启动
- 数据库名为 `supermarket`
- 用户名为 `appuser`
- 密码为 `123456St$`

如果你的数据库配置不同，请手动修改 `db_conn.py` 中的连接参数。

## 7. 项目运行步骤

### 第一步：进入项目目录
将项目解压后，进入项目根目录：

```bash
cd SupermarketSystem

```

---

### 方法二：手动运行

#### 第一步：打开 Docker Desktop

先确认 Docker Desktop 已经打开，并且数据库容器 `opengauss` 正在运行。

#### 第二步：进入项目目录

```powershell
cd 项目目录
```

#### 第三步：激活虚拟环境

```powershell
.venv\Scripts\activate
```

#### 第四步：初始化数据库（首次运行时）

如果你是第一次运行项目，或者想重置数据库，请执行：

```powershell
python init_db.py
```

该脚本会：

- 删除旧表
- 重新建表
- 插入初始用户
- 插入初始商品
- 插入部分历史销售记录

注意：**执行该脚本会清空原有数据库中的旧数据。**

#### 第五步：启动系统

```powershell
python app.py
```

浏览器访问：

```text
http://127.0.0.1:5000
```

## 注意事项

### 1. 初始化数据库会清空旧数据

执行：

```powershell
python init_db.py
```

会删除现有表并重新建立，请谨慎操作。

### 2. 数据库必须先可连接

如果 Docker 没有打开，或者 `opengauss` 容器没有运行，系统会无法连接数据库。

### 3. 若数据库配置不同，请修改 `db_conn.py`

如果你的数据库用户名、密码、端口、数据库名不同，请手动修改：

- `db_conn.py`

中的连接参数。

## 常见问题

### 1. 双击启动没有反应

请检查：

- Docker Desktop 是否已启动
- `opengauss` 容器是否存在
- `.venv` 虚拟环境是否存在

### 2. 页面打开但无法登录

请确认是否已经执行过：

```powershell
python init_db.py
```

### 3. 数据库连接失败

请检查：

- 数据库容器是否启动
- 本机端口 `15432` 是否可用
- 数据库名是否为 `supermarket`
- 用户名是否为 `appuser`
- 密码是否为 `123456St$`
